# Kateb PHP API — راهنمای نصب

## فایل‌ها

| فایل | کاربرد |
|------|--------|
| `config.php` | تنظیمات اتصال به دیتابیس (نام دیتابیس، کاربری، رمز) |
| `index.php` | فایل اصلی API — تمام درخواست‌ها اینجا پردازش می‌شوند |
| `.htaccess` | تنظیمات سرور برای CORS و امنیت |

## مراحل آپلود

1. وارد پنل هاستینگ خود شوید (cPanel، DirectAdmin و ...).
2. به File Manager بروید و به پوشه `public_html` بروید.
3. یک پوشه جدید به نام `api` بسازید.
4. تمام فایل‌های این پوشه (`config.php`، `index.php`، `.htaccess`) را داخل `public_html/api/` آپلود کنید.
5. نتیجه: آدرس API شما خواهد شد:
   ```
   https://yourdomain.com/api/index.php
   ```

## تنظیم دیتابیس

1. در پنل هاست، یک دیتابیس MySQL جدید بسازید (مثلاً `kateb`).
2. یک کاربر برای دیتابیس بسازید و رمز عبور قوی انتخاب کنید.
3. کاربر را به دیتابیس متصل کنید (Add User to Database) و **All Privileges** را بدهید.
4. فایل `config.php` را باز کنید و مقادیر زیر را تغییر دهید:

```php
'db_host' => 'localhost',          // معمولاً همین می‌ماند
'db_name' => 'kateb',      // نام دیتابیس
'db_user' => 'kateb',      // نام کاربری دیتابیس
'db_pass' => 'CHANGE_THIS_PASSWORD', // رمز عبور دیتابیس
```

5. فایل `config.php` را ذخیره و دوباره آپلود کنید.

## ساخت خودکار جداول

نیازی به دستی ساخت جدول نیست. اولین باری که API فراخوانی شود، تمام جداول مورد نیاز به‌طور خودکار در دیتابیس ساخته می‌شوند.

یک کاربر مدیر پیش‌فرض هم ساخته می‌شود:
- **شماره موبایل:** `09120000000`
- **رمز عبور:** `admin123`

بعد از اولین ورود، رمز عبور را از پنل مدیریت تغییر دهید.

## اتصال اپلیکیشن

در اپلیکیشن، وارد صفحه مدیریت شوید و در تب **«دیتابیس»** آدرس API خود را وارد کنید:

```
https://yourdomain.com/api/index.php
```

روی **«تست اتصال»** بزنید تا مطمئن شوید ارتباط برقرار است. سپس **«ذخیره آدرس»** را بزنید.

## پیشنیازها

- PHP 7.4 یا بالاتر
- اکستنشن `pdo_mysql` فعال باشد
- اکستنشن `curl` فعال باشد
- `allow_url_fopen = On` (برای فراخوانی API های خارجی)
